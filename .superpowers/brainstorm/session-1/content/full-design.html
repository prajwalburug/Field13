Full Design: Tab by Tab

Tab 1: Command Center

Hero Banner — 180px tall, Ghibli pixel-art background, live clock, "Good morning" greeting, status indicator
Scorecard — 2×2 grid: Active Clients, Operators, Monthly Revenue, Active Programs. Reads 00-Command-Center/?? Home.md
Calendar — Scrollable day rail + agenda list. Reads data/calendar.json (from refresh script)
Action Queue — Approve/dismiss rows. Reads data/action-queue.json (manual or script)
Skills Tiles — Grid of skill buttons, each fires claude -p. Shows loading state while running.
Engagements — Client rows with stage, last activity, blocker indicator. Reads vault files.
Operator Network — Roster from 03-Operator-Network/
Pipeline — Sales stages from 06-CRM/Pipeline Overview.md

Tab 2: News & Signals

RSS Dashboard plugin feeds rendered in Obsidian Web Viewer, styled to match dashboard.
Or: custom-built feed reader within the plugin using rss-parser in a Node.js refresh script.
Features: Search bar, source filter, grid/list toggle, bookmark, timeline sort

Tab 3: Intelligence

Meeting transcripts from Operations/Meetings/ — list view, expand inline
Email highlights from data/gmail-highlights.json
Each section is recent items list; click to expand full content

Error & Empty States

📭 Empty data — "No data yet. Run the refresh script." + a Refresh button
⚠️ File not found — "Source file missing at data/calendar.json"
⏳ Loading — Skeleton cards (pulsing gray blocks)
🔁 Manual refresh — Every card has a small ↻ refresh button

Refresh Scripts

.claude/scripts/cc-refresh-calendar.sh — Google Calendar API → data/calendar.json
.claude/scripts/cc-refresh-rss.sh — RSS feeds → data/news.json
Run via cron (Linux) or Task Scheduler (Windows), or manually from dashboard button
