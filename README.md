# Trust Engine Website

A React website for Trust Engine - a service that builds authentic operator distribution for VC portfolios.

## Features

- Modern, minimalistic design focused on trust and clarity
- Responsive layout for all device sizes
- Built with React and Vite for fast development
- Includes Home, About, Services, and Contact pages
- Optimized for SEO and performance

## Pages

- **Home**: Main landing page with problem/solution explanation
- **About**: Company story, philosophy, and team information
- **Services**: Detailed service offerings and pricing
- **Contact**: Contact form and information

## Tech Stack

- React 18
- Vite
- React Router DOM
- React Icons
- React Hook Form
- Zod (for form validation)
- CSS Modules (via index.css)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Design Principles

- Trust-first approach with clean, professional aesthetics
- Minimalistic layout that emphasizes key messages
- Clear visual hierarchy guiding users toward action
- Authentic, human-centered design elements
- Responsive design for optimal viewing on all devices
